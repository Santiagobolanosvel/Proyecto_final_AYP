# Sistema de Gestión de Planta – Industrias Reymón S.A.S.
Aplicación de escritorio desarrollada en **Python** con interfaz gráfica en **Tkinter** para el control de proyectos de fabricación, actividades, horas trabajadas, consumibles de bodega, estado de herramientas y seguimiento de costos y tiempos.
